# SkillGap AI - Prompts Used

This project was built using Bolt.new free version. Only 3 prompts used in this version.

## Prompt 1 - Initial Project Build
Build SkillGap AI - AI Career Roadmap platform for students. Features: Home page, Login Signup with Supabase Auth, Dashboard, Roadmap page with role selection and 4 week plan, Quiz page with 5 questions, Resume Builder with form and preview. Design clean modern blue white, mobile responsive, React Vite TypeScript Tailwind CSS. Use Supabase client from environment variables VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY. Do not hardcode keys.

## Prompt 2 - About Page
Add About page for SkillGap AI. Content: About SkillGap AI, Built by Cyril P Jose, features list, GitHub and LinkedIn links placeholder. Add link in navbar and footer.

## Prompt 3 - WhatsApp Share Feature
Add WhatsApp Share button on Roadmap page. When user clicks, open WhatsApp with prefilled text of their roadmap progress. Use https://wa.me/?text= format.

## End of Bolt Version
Bolt work completed upto WhatsApp Share only. No further prompts used in Bolt.
Bolt free version badge cannot be removed, this is Bolt limitation.

## Secrets Handling
No real API keys stored in GitHub. Supabase keys are stored only in Bolt Secrets for preview and in Netlify Environment Variables for deployment.
